# Testimonial photo uploads

Add customer-approved before/after images to this folder, then set their paths in the `testimonials` list at the top of `script.js`.

Example:

```js
{
  quote: '“Your testimonial.”',
  name: 'Client A',
  focus: 'Wellness coaching',
  beforeImage: 'assets/testimonials/client-a-before.jpg',
  afterImage: 'assets/testimonials/client-a-after.jpg'
}
```

Use photos only with the customer’s permission. Keep the existing individual-results disclaimer visible with every before/after pair.
